CLAW CONTROL {VERSION} - for the MSI Claw A8 only

Fast, controller-friendly quick settings for the MSI Claw A8, opened with the MSI Center M
button. Made and tested on the MSI Claw A8 (board MS-1T8K) only; other devices are refused.

INSTALL
1. Unzip this folder anywhere (for example Downloads).
2. Double-click Install.cmd and allow the admin prompt.
3. Press the MSI Center M button to open the panel.

The setup checks that this is a Claw A8, and warns if MSI Center M or the AMD graphics driver is
missing. It installs to C:\Program Files\ClawControl and starts with Windows.

UNINSTALL
Double-click "Uninstall Claw Control.cmd" in C:\Program Files\ClawControl (or Uninstall.cmd
here). MSI Center M gets its button back.

Prefer a normal installer? Use ClawControl-Setup-{VERSION}.exe from the same release page; it
does the same and adds Claw Control to Settings > Apps > Installed apps.
